# Devinette  - Java

Jeu de devinettes où l'ordinateur choisit un nombre aléatoire entre 1 et 100.  
Le joueur dispose de maximum 10 essais pour deviner le nombre.

## Fonctionnalités

- Génération d'un nombre aléatoire entre 1 et 100
- Maximum 10 essais
- Indications "plus grand" ou "plus petit"
- Messages de victoire et de défaite
